Core vs. modules, at a glance

The seven boxes in the center are the only mandatory pieces — install those and you have a working, empty platform. Everything around it is opt-in: pick what a use case needs, skip the rest, add more later. Dashed spokes mark where each group plugs into the core through the gateway’s module registry, not into each other.
